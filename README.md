# 📝 Task Manager API

Uma API RESTful desenvolvida com **Java** e **Spring Boot** para o gerenciamento de tarefas diárias. O projeto foi construído aplicando boas práticas de desenvolvimento de software, arquitetura em camadas e controle de versão profissional via Git/GitHub.

---

## 📌 Funcionalidades

- [x] **Criar tarefa:** Permite o cadastro de uma nova tarefa com título, descrição e status.
- [x] **Listar tarefas:** Consulta todas as tarefas cadastradas ou filtra por id/status.
- [x] **Atualizar tarefa:** Atualiza os dados de uma tarefa existente.
- [x] **Deletar tarefa:** Remove uma tarefa do sistema.

---

## 🛠️ Tecnologias Utilizadas

* **Linguagem:** Java 17+
* **Framework:** Spring Boot 3+
  * Spring Web
  * Spring Data JPA
* **Banco de Dados:** H2 Database / PostgreSQL
* **Ferramenta de Build:** Maven / Gradle
* **Testes/Documentação de API:** Postman / Insomnia / Swagger
